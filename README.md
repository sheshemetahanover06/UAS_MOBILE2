# AyoMinum 
AyoMinum adalah aplikasi Android yang membantu pengguna menjaga kebutuhan cairan tubuh setiap hari. Aplikasi ini menyediakan fitur pengingat minum, pencatatn konsumsi air, riwayat minum, serta rekomendasi target minum harian berdasarkan data pengguna. 

# Deskripsi 
Kurangnya konsumsi air dapat menyebabkan dehidrasi, menurunkan konsetrasi, dan berdampak pada kesehatan tuhuh. AyoMinum hadir sebagai solusi untuk membantu pengguna membangun kebiasaan minum air secara teratur melalui pengingat minum otomatis dan pemantauan konsumsi air harian. 

# Tujuan 
- Membantu pengguna memenuhi kebutuhan cairan tubuh.
- Mengingatkan pengguna untuk minum air secara berkala.
- Mencatat riwayat konsumsi air setiap hari.
- Memberikan rekomendasi target minum berdasarkan data pengguna.

# Fitur 
- Login pengguna
- Dashboard informasi hidrasi
- Menambahkan konsumsi air
- Riwayat konsumsi air
- Penganturan target minum
- Notifikasi pengingat minum
- Rekomendasi target minum harian (berdasarkan AI)
- Penyimpanan target harian

# Teknologi 
- Android Studio
- Java
- XML
- Git & Github

# Kesimpulan

Aplikasi AyoMinum merupakan aplikasi mobile yang dirancang untuk membantu pengguna menjaga kebutuhan cairan tubuh setiap hari melalui fitur pengingat minum air, pencatatan konsumsi, riwayat minum, pengaturan target harian, serta rekomendasi kebutuhan cairan berdasarkan data pengguna. Dengan adanya aplikasi ini, pengguna dapat memantau progres konsumsi air secara lebih mudah dan membangun kebiasaan minum air yang lebih teratur.

Pengembangan aplikasi ini juga memberikan pengalaman dalam merancang antarmuka pengguna (UI/UX), mengimplementasikan fitur-fitur pada Android Studio menggunakan bahasa Java, serta menerapkan konsep notifikasi sebagai pengingat otomatis. Diharapkan aplikasi AyoMinum dapat menjadi solusi sederhana yang bermanfaat untuk meningkatkan kesadaran masyarakat akan pentingnya menjaga hidrasi tubuh.
